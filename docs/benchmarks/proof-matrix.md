# benchmark acceptance and proof matrix

This matrix distinguishes implemented offline fixture behavior from comparisons that require independent reviewers or actual products. The saved [validation output](evidence/validation.txt) and [initial result map](evidence/scenario-result-map.json) are historical offline records. The later [two-skill model comparison](../development/model-fit.md) used scenario A on the selected model and received independent agent review; it did not qualify full roles or an integrated pipeline. The matrix below describes the original benchmark-package checks unless a later result is explicitly linked.

The active bundle is v1.0.4. B v1.0.2 adds exact spans for its already reported synthetic denominators and updates its reference; A/C remain v1.0.1. Earlier bundle versions existed only during local fixture drafting and changed before any model or pilot pass; no pass from those drafts is claimed. The changed-packet test demonstrates how a later historical result must remain visible yet untested for a new packet, test arm, rubric, build, or configuration.

The packet defines later comparisons and scoring. The linked skill experiment adds source-level findings, but neither record establishes a live baseline, selected-model advantage, human-adjudicated scientific validity or full-pipeline performance.
