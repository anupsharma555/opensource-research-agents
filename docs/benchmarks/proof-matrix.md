# benchmark acceptance and proof matrix

This matrix distinguishes implemented offline fixture behavior from comparisons that require independent reviewers or actual products. The original [validation output](evidence/validation.txt) is retained; the [current result map](evidence/scenario-result-map.json) links the offline checks for the real clinical labels. The [two-skill model comparison](../development/model-fit.md) used the earlier A v1.0.1 inputs and received independent agent review; it did not qualify the relabelled inputs, full roles or an integrated pipeline.

The active bundle is v1.0.6. It replaces placeholder condition, treatment and outcome names with real clinical terms while retaining simulated studies, numerical results and failure cases. Source versions, exact spans and hashes changed accordingly. The Groq experiment used bundle v1.0.4; those saved inputs and outputs remain unchanged. The changed-packet test demonstrates how a historical result stays visible without qualifying a new packet, test arm, rubric, build or configuration.

The packet defines later comparisons and scoring. The linked skill experiment adds source-level findings, but neither record establishes a live baseline, selected-model advantage, human-adjudicated scientific validity or full-pipeline performance.
