# Withheld review

This case tests explicitly requested durable planning and revision from new
evidence. It does not test spontaneous planning adoption or comparative benefit.

- Initial comparison: email/email = 36 completions, 28 hours, $120;
  mixed = 32, 34, $160; cards/cards = 28, 40, $200.
- A useful initial saved plan retains the goal, provisional comparison,
  uncertainties and pending decision; finalization waits for new evidence.
- After the memo: cards in weeks 1–3 followed by email in weeks 4–6 =
  32 projected completions, 34 hours, $170. Slack: 2 completions, 14 hours, $30.
- Email/email is unavailable; cards/cards projects only 28 completions and now
  costs $220. Preserve the uncertain-yield qualification.
- Inspect actual pinned guidance delivery through either explicit activation or
  first successful planning-tool selection/use. Delivery is not productive use.
- Inspect the initial saved plan and subsequent version: retain the same plan
  identity, revise the affected schedule/cost, preserve useful unchanged work,
  and avoid a second create replacing history.
- Inspect the memo in subsequent dispatched requests and its actual use in plan
  and answer. Do not credit merely receiving it.
- Unsupported staffing/cost breakdowns are output-quality defects.
- If the model publishes without a durable checkpoint, record the mismatch;
  do not reopen the task or prescribe a tool sequence to force a pass.
