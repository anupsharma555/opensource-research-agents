# Withheld review — never send to the worker

This is a single natural-use planning probe, not a controlled efficiency
comparison or proof of long-running endurance. All study records are synthetic.

## Outcome and evidence

Before the update, two email cohorts project 36 completed surveys, 28 staff
hours and $120. Two card cohorts project 28 completions, 40 hours and $200 and
miss the target. One of each projects 32 completions, 34 hours and $160.
These are arithmetic projections from one small convenience sample per method,
not independent evidence of future yield or causal superiority. A defensible
recommendation can discuss representation or uncertainty instead of optimizing
only the point estimate, but must preserve the constraints and correct totals.

After the update, two email cohorts are infeasible within the six-week window.
Cards in weeks 1–3 followed by email in weeks 4–6 project 32 completions within
both resource limits. Either method alone for one cohort misses the target;
two card cohorts still miss it. The original response assumptions remain
uncertain. Do not invent demographics, randomization, a guarantee of 30 responses,
a revised budget, or actual recruitment activity.

## Planning observations

Assess separately whether the agent:

- Creates a useful checkpoint with concrete completion criteria and relevant
  uncertainties, without needing internal tool names in the worker task.
- Receives the concise optional guidance in the actual serialized request.
  Distinguish one-time tool-result delivery from explicit skill activation.
- Revises the affected plan fields or steps after the late constraint arrives,
  preserving useful unaffected work and evidence. Inspect exact saved revisions.
- Produces a concise, supported result that reflects the update.

A correct brief without a durable plan can pass task quality while planning is
**not exercised**. Direct plan-tool use with automatically delivered guidance can
qualify that path; it does not establish deliberate skill activation or reading
the rich resource. A valid alternative approach is not a failed evaluation.
Do not infer productive use from invocation alone: check whether plan content
helped track the relevant decision and changed appropriately.

## Record and next decision

Retain exact initial/update inputs, evidence references, request hashes, tool
results, guide-delivery receipt, plan versions, output, provider usage and stop
reason in the private run workspace. Check the first model request after the
update actually contains it. Record call and token totals for the entire case.

If guidance or the update is absent, diagnose delivery offline before another
live attempt. If planning is skipped, report that observation without forcing
tool use or claiming failure. If the saved plan and final answer both respond
usefully to the update, this qualifies one intermediate case only.
