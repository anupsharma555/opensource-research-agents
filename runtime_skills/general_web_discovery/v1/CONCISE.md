# General web discovery

Use scholarly databases for research literature; use general web discovery when broader or current context helps. Honor no-external-search limits. When useful, request `browser_search` and select it only after a grant. Its snippets, citation markers, and URLs are discovery leads, not inspected evidence. For a literal URL, use its saved hit ID with `fetch_source`; inspect retained text before citing or making a source-backed claim. Opaque markers and failed fetches do not justify invented URLs or findings.
