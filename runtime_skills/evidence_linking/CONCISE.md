# Evidence linking · concise

Link a narrow claim to an inspected passage in the supplied versioned `EvidencePacket`, marking support, challenge, or context. Preserve the population, comparison, outcome, time and contrary evidence. Copy `source_id`, `source_version` and `span_id` verbatim into a compact reference list, using code spans so ASCII hyphens remain unchanged. Retain artifact identity, hash and access surface in that reference record, separate from the readable answer.

Use facts explicitly reported in an abstract. Keep each omission attached to its own source: silence in one supplied abstract is not proof that another study or its full publication lacked the information. Distinguish reported numbers from arithmetic you derive; preserve the source's interval wording without inventing its type or confidence level. Describe effect magnitude or clinical importance only against a stated criterion. Missing published variance does not by itself make calculation from binary counts impossible; distinguish mathematical availability from whether pooling is scientifically appropriate.

Give a short answer to the actual question, one source-backed reason for its uncertainty, and targeted next information needs. Continue using supported partial evidence while missing details are sought. Save the candidate link for independent semantic review. The helper checks identity and locator membership, not whether the passage warrants the claim.
