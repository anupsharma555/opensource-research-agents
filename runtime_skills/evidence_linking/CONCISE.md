# Evidence linking · concise

Use when a claim must point to inspected source text. Input is a versioned `EvidencePacket` from the shared evidence store, the proposed claim, its exact locator, and whether the passage is offered as support, challenge, or context. Choose only a locator in that packet; retain artifact ID, version, hash, and access surface. State population, comparison, outcome, time and uncertainty when they matter. A published abstract supports only facts it explicitly reports. If a needed detail is absent, mark it unknown and request that detail; do not borrow it from another study. Save the candidate link for independent semantic support review. The helper checks identity and locator membership; it does not decide whether the passage actually proves the claim.
