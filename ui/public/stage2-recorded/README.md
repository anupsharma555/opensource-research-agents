# Recorded Stage 2 demonstration

These project-owned offline fixtures were generated by:

```sh
.venv/bin/python -B -m ora.state.demo --state-dir .local/stage2/demo-state-v6 --export-dir .local/stage2/atlas
```

The parent and child exports were copied unchanged from that export directory.
They are read projections of persisted StateStore/domain records, with simulated
benchmark sources and public model configuration. No model or search provider
was invoked. Controlled-clock timestamps are not observed provider latency.

Open the app with `?recorded=stage2`, or choose **Open recorded Stage 2 review**
in Previous samples. Only the two fixed JSON paths in this directory are loaded.
No private live store, credentials, or raw live-provider inputs belong here.

To refresh these files, rerun the demo against a fresh ignored state directory,
inspect the exports, then copy parent.json and child.json together. Do not edit
the generated JSON by hand or silently substitute a live run.
